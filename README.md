# AskSmth

AskSmth - статический сайт вопросов и ответов, созданный на HTML, CSS и Bootstrap.

## Запуск проекта

### Способ 1. Через PyCharm

1. Скачайте и распакуйте архив с проектом.
2. Откройте PyCharm и выберите `File - Open`.
3. Выберите папку `AskSmth`.
4. Откройте файл `public/index.html`.
5. Нажмите правой кнопкой мыши и выберите `Open in Browser`.

### Способ 2. Через локальный сервер

1. Скачайте и распакуйте архив с проектом.
2. Откройте терминал в папке `AskSmth`.
3. Запустите сервер командой:

   ```bash
   python3 -m http.server 8000 --directory public
   ```

4. Откройте в браузере `http://localhost:8000/index.html`.
5. Для остановки сервера нажмите `Ctrl+C` в терминале.

## Страницы

- `index.html` - главная страница со списком вопросов.
- `question.html` - вопрос, ответы и форма ответа.
- `ask.html` - создание нового вопроса.
- `login.html` - вход на сайт.
- `signup.html` - регистрация.
- `profile.html` - настройки профиля.
- `tag.html` - список вопросов по тегу.
- `base.html` - общий макет страницы.

Все HTML-файлы находятся в папке `public`.

## Структура проекта

- `public/static/css/` - Bootstrap и собственные стили.
- `public/static/js/` - JavaScript Bootstrap.
- `public/static/img/` - изображения и SVG-иконки.
